# werewolf

LLM multi-agent One Night Werewolf experiment. A Supervisor and Participants (OpenAI-compatible clients) play via prompt-encoded Caesar-style ciphers in `prompt/`. Run with `OPENAI_API_KEY` and `BASE_URL` set; entry points `game.py` / `test_1.py`. `extract_rules.py` OCRs rule images with EasyOCR. Sample run log in `record/`.
